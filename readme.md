# Task Manager

Sistema de gestão de tarefas desenvolvido com arquitetura Full-Stack.

## 🚀 Tecnologias

- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, TypeScript, Prisma ORM
- **Banco de Dados:** PostgreSQL
